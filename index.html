产品设计说明

这个页面写给评审看：为什么做、怎么做、靠什么建立信任、之后往哪走。

一、真实存在的四个痛点

快递点排队 20 分钟起

下课时间和驿站高峰期完全重合，一个中号快递能吃掉半个午休。

→ 顺路的同学代取，5 元换回 20 分钟

群里喊话，喊完就沉底

班群、楼栋群里发一条「谁帮我带个饭」，十分钟就被新消息刷走，成交全靠运气。

→ 任务化发布，可检索、可筛选、可追踪

陌生人交易没有信任基础

让不认识的人拿自己的快递、进自己的宿舍楼，出问题没有追责路径。

→ 校园卡实名 + 双向评价 + 平台担保

想赚点零花钱，但没渠道

学生的时间碎片化，兼职要整块时间通勤，跑腿恰好是「顺路 5 分钟」的活。

→ 按单结算，一天顺路 3 单 ≈ 一顿饭钱

二、核心流程：六步闭环

  1. 1发布选类型、填取送点与酬劳，1 分钟完成
  2. 2匹配按校区、楼栋顺路度推送给附近同学
  3. 3接单实名跑腿者接单，双方建立临时会话
  4. 4履约取件与送达各拍一张照，进度实时同步
  5. 5确认发布者确认完成，酬劳从托管账户结算
  6. 6互评双向评价计入信用分，沉淀长期信任

三、信任机制：这个产品真正的护城河

校园卡实名认证

学号 + 校园卡照片人工审核，只对同校开放，校外无法注册。

酬劳平台托管

发布时先冻结酬劳，确认完成后才打给跑腿者，避免赖账和跑单。

双向评价与信用分

发布者和跑腿者互相评分，只累积不重置，差评直接影响派单优先级。

全程留痕

取件、送达两次拍照打卡，时间地点自动记录，纠纷时作为判责依据。

四、产品结构与商业模式

功能结构

  • 任务广场：按类型 / 校区 / 酬劳 / 距离筛选，卡片直接展示取送路线
  • 发布任务：四类模板，取送点、时间窗、酬劳、加急标记
  • 我的任务：发布与接单双视角，待接单 → 进行中 → 已完成状态流
  • 信用档案：信用分、等级、勋章、评价记录、规则透明可查
  • 消息与通知：接单提醒、超时预警、送达确认（后续迭代）

怎么赚钱

  • 提现通道费：跑腿者提现收 1%，覆盖支付与担保成本，发布者免费
  • 校园商家合作：食堂、便利店、打印店入驻发单，按成交抽佣
  • 加急服务费：加急单平台收 1 元调度费
  • 不做的：不向学生收会员费、不做竞价排名，避免信用体系被钱污染

五、迭代路线

V1 任务广场与信用档案当前跑通发布、接单、完成、评价的最小闭环，验证同校供需是否成立。
V2 顺路匹配接入课表与常走路线，把「顺路单」推到最可能接的人面前，把接单时长压到 3 分钟内。
V3 信用分权益化高信用用户享受优先派单、免押金、图书馆座位预约等校内权益，让信用真的值钱。
V4 多校区复制把认证、结算、纠纷处理流程标准化，向同城高校复制，形成区域校园互助网络。
