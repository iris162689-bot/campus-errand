# 搭把手 · 校园跑腿互助平台

校园内的可信互助跑腿平台产品原型：代取快递、代买物品、代占座，通过校园实名认证、酬劳托管、双向评价与信用分，把「群里喊一嗓子」变成可追踪、可追责的任务流。

## 在线访问

部署在 GitHub Pages，域名固定，可持续迭代：

> https://<你的用户名>.github.io/campus-errand/

## 产品结构

| 模块 | 说明 |
| --- | --- |
| 任务广场 | 按类型 / 关键词 / 排序筛选，卡片直接展示取送路线、酬劳、截止时间与发布者信用 |
| 发布任务 | 四类模板（取快递 / 代买 / 占座 / 其他），取送点、时间窗、酬劳、加急标记 |
| 我的任务 | 发布与接单双视角，待接单 → 进行中 → 已完成状态流，支持标记送达与确认完成 |
| 信用档案 | 信用分、等级、勋章墙、评价记录、公开的信用分规则表 |
| 产品设计 | 痛点 → 方案映射、六步核心流程、信任机制、商业模式、迭代路线 |

## 核心设计判断

- **信任是护城河**：校园卡实名（只对同校开放）+ 酬劳平台托管 + 双向评价 + 取送两次拍照留痕。
- **信用不能被钱污染**：不向学生收会员费、不做竞价排名，信用分只来自真实履约。
- **降低发布门槛**：任务标题、取送点写到楼栋房间号，比「帮个忙」类模糊描述接单快得多。

## 技术说明

单文件静态站点（`index.html`），零依赖、零构建，原生 HTML/CSS/JS。任务数据用 `localStorage` 持久化，用于演示完整的发布 → 接单 → 完成闭环。

## 本地预览

直接用浏览器打开 `index.html` 即可。
